# Formação do Investidor • Investment Engine V1.6.0

## Entrega

- Página institucional responsiva para o domínio principal.
- Roteamento previsto para `www` e `app`.
- Login OIDC na interface Streamlit com lista de e-mails permitidos.
- Endereço da API configurável por ambiente e oculto na produção.
- FastAPI e PostgreSQL isolados em rede interna.
- PostgreSQL sem credencial padrão e sem porta pública.
- HTTPS automático por proxy Caddy.
- Documentação interativa da API desativável em produção.
- Cabeçalhos de segurança e hosts confiáveis.
- Dockerfile, Compose de produção, healthchecks e reinicialização automática.
- Scripts Windows para preparação e backup.
- Segredos excluídos do repositório e das imagens.

## Limite deliberado

A V1.6.0 é um beta privado de proprietário único e preserva o banco existente. A V1.6.1 deverá introduzir identidade no modelo de dados e isolamento multiusuário antes da abertura pública.
