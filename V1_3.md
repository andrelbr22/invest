# Investment Engine V1.3

V1.3 é a primeira versão de integração visual do projeto.

## Objetivos

- Preservar o Investment Engine como núcleo independente.
- Entregar uma página Streamlit que consome somente a API para leitura principal.
- Exibir Ações e FIIs, estratégias Padrão/CNPI/ALB, scores e Data Quality.
- Disponibilizar análise individual, histórico de preços, scores e valuations.
- Preparar a substituição gradual das chamadas diretas do Streamlit antigo.

## Novos endpoints

- `GET /screen/db/fiis/{strategy_id}`
- `GET /assets/{ticker}/prices`
- `GET /assets/{ticker}/scores/history`
- `GET /assets/{ticker}/valuations`

## Interface

`examples/streamlit_v13_integrated.py`

A interface é deliberadamente de validação funcional. A etapa seguinte poderá refazer o design visual com foco em mobile/web sem alterar o motor.
