# Patch V1.12.1

Este patch cumulativo atualiza a V1.11.1 ou a V1.12.0 diretamente para a
V1.12.1.

Ele inclui a entrega segura dos resultados do GitHub para a Oracle, o progresso
por ativo, a atualização automática, o cancelamento seguro e a repetição apenas
de ativos com falha ou pendentes.

Os arquivos locais de segredos não fazem parte do pacote e não são
sobrescritos.
