Política de Privacidade

Esta página é uma minuta técnica e deverá passar por revisão jurídica antes da abertura ao público.

Dados e finalidade

No beta privado, dados de identificação são utilizados para autenticar o acesso. Dados de carteira e simulações são processados para prestar as funcionalidades solicitadas.

Segurança

O acesso é protegido, a comunicação utiliza HTTPS e o banco de dados permanece em rede privada. Backups e registros operacionais seguem política de retenção controlada.

Direitos do titular

O canal de contato para acesso, correção e exclusão de dados será divulgado antes do lançamento público.

Versão

Minuta técnica de 22 de agosto de 2026. Não utilizar como texto jurídico definitivo.
