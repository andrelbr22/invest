# Formação do Investidor V1.10.1

## Correção

O workflow agora executa `scripts.run_weekly_backtests` como módulo e o próprio script também prepara o caminho do projeto quando for aberto diretamente. Isso elimina o erro `ModuleNotFoundError: No module named 'investment_engine'`.

## Backtests solicitados pelo site

Na conta proprietária, abra **Administração > Backtests oficiais > Lote oficial completo**.

- a tela começa com as ações do filtro Padrão;
- é possível selecionar até 100 ativos;
- um único botão envia o pedido ao GitHub Actions;
- o processamento continua mesmo se o site for fechado;
- o histórico do lote permanece no banco compartilhado.

A credencial é lida somente dos Secrets do Streamlit. Ela não é exibida na página e não é enviada ao navegador.

## Banco de dados

Não há migração nova nesta versão.
